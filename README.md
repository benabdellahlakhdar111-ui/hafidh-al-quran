# حافظ القرآن
واجهة أولية عربية متجاوبة لمنصة حفظ القرآن الكريم.

## تشغيل محلي
افتح `index.html` في متصفح حديث. للحصول على أفضل فرصة لاستخدام التعرف الصوتي، جرّب Chrome مع اتصال آمن (HTTPS) واسمح باستخدام الميكروفون.

## النشر عبر GitHub Pages
1. ارفع `index.html` إلى جذر المستودع `hafidh-al-quran`.
2. افتح Settings ثم Pages.
3. من Build and deployment اختر Deploy from a branch.
4. اختر `main` والمجلد `/ (root)` ثم Save.
5. انتظر ظهور رابط الموقع في صفحة Pages.

## حدود النسخة الحالية
هذه واجهة تجريبية. النطق المستخدم للتوجيه هو تحويل نص إلى كلام في المتصفح، وليس تلاوة قرآنية معتمدة. والتعرف على كلام المتعلم تجريبي ولا يصح اعتباره حكماً على صحة التلاوة أو التجويد. يلزم في النسخة الإنتاجية ربط تلاوات موثوقة ومحرك متخصص لمقارنة التلاوة، مع خادم خلفي آمن وقاعدة بيانات وموافقة ولي الأمر على معالجة صوت الطفل.
